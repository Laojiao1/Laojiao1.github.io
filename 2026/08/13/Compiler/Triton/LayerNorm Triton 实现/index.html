LayerNorm Triton

LayerNorm Triton 实现

LayerNorm（层归一化）的前向传播确实直观，但它的 反向传播（Backward Pass）推导 则是 CUDA/Triton 算子优化中最精妙、也最考验物理直觉的经典环节之一。

下面我将先简单介绍其数学思想，并采用两种数学推导的方式讲解反向传播，最后与 Triton 官方示例代码进行映射并总结。

数学思想：LayerNorm 到底在干什么？

假设输入为一个行向量 x=[x1,x2,…,xN]\mathbf{x} = [x_1, x_2, \dots, x_N]x=[x1​,x2​,…,xN​]（长度为 NNN，即 n_cols），LayerNorm 的前向公式为：

  1. 均值：μ=1N∑i=1Nxi\mu = \frac{1}{N} \sum_{i=1}^N x_iμ=N1​∑i=1N​xi​
  2. 方差：σ2=1N∑i=1N(xi−μ)2\sigma^2 = \frac{1}{N} \sum_{i=1}^N (x_i - \mu)^2σ2=N1​∑i=1N​(xi​−μ)2
  3. 归一化（Standardization）：x^i=xi−μσ2+ϵ=(xi−μ)⋅σinv\hat{x}_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}} = (x_i - \mu) \cdot \sigma_{\text{inv}}x^i​=σ2+ϵ​xi​−μ​=(xi​−μ)⋅σinv​ （其中 σinv=1σ2+ϵ\sigma_{\text{inv}} = \frac{1}{\sqrt{\sigma^2 + \epsilon}}σinv​=σ2+ϵ​1​）
  4. 仿射变换（Scale and Shift）：yi=γix^i+βiy_i = \gamma_i \hat{x}_i + \beta_iyi​=γi​x^i​+βi​

关键物理直觉：梯度的“双重泄露”

在前向传播中，每个 xix_ixi​ 都通过 **三种 **渠道影响了最终的输出 yyy：

  1. 直接渠道：xix_ixi​ 直接作为分子参与计算 x^i\hat{x}_ix^i​。
  2. 间接渠道 1（均值 μ\muμ）：xix_ixi​ 贡献了均值 μ\muμ，而 μ\muμ 会影响这一行所有元素的归一化。
  3. 间接渠道 2（方差 σ2\sigma^2σ2）：xix_ixi​ 贡献了方差 σ2\sigma^2σ2，而 σ2\sigma^2σ2 同样会影响这一行所有元素的归一化。

因此，在反向传播计算上游梯度 ∂L∂xi\frac{\partial L}{\partial x_i}∂xi​∂L​ 时，链式法则必须把这三条路径的梯度全部累加起来！

详细数学推导（三步拆解法）

假设从上一层传回的损失函数 LLL 关于 yiy_iyi​ 的梯度为

dyi=∂L∂yid y_i = \frac{\partial L}{\partial y_i} dyi​=∂yi​∂L​

第一步：对参数 γ\gammaγ 和 β\betaβ 求导（极简）

根据

yi=γix^i+βiy_i = \gamma_i \hat{x}_i + \beta_i yi​=γi​x^i​+βi​

∂L∂βi=dyi⋅1  ⟹  dβi=dyi\frac{\partial L}{\partial \beta_i} = d y_i \cdot 1 \implies \mathbf{d\beta_i = d y_i} ∂βi​∂L​=dyi​⋅1⟹dβi​=dyi​

∂L∂γi=dyi⋅x^i  ⟹  dγi=dyi⋅x^i\frac{\partial L}{\partial \gamma_i} = d y_i \cdot \hat{x}_i \implies \mathbf{d\gamma_i = d y_i \cdot \hat{x}_i} ∂γi​∂L​=dyi​⋅x^i​⟹dγi​=dyi​⋅x^i​

注意：γ\gammaγ 和 β\betaβ 是跨 Batch/Row 共享的，所以最终的 dγd\gammadγ 和 dβd\betadβ 需要沿 Row 维度（n_rows）求和。

同时，我们定义对归一化特征 x^i\hat{x}_ix^i​ 的梯度为：

dx^i=∂L∂x^i=dyi⋅γid\hat{x}_i = \frac{\partial L}{\partial \hat{x}_i} = d y_i \cdot \gamma_i dx^i​=∂x^i​∂L​=dyi​⋅γi​

第二步：对中间变量 μ\muμ 和 σ2\sigma^2σ2 求导

定义标准差倒数

σinv=(σ2+ϵ)−1/2\sigma_{\text{inv}} = (\sigma^2 + \epsilon)^{-1/2} σinv​=(σ2+ϵ)−1/2

1. 关于方差 σ2\sigma^2σ2 的梯度：

只有 x^k=(xk−μ)⋅(σ2+ϵ)−1/2\hat{x}_k = (x_k - \mu) \cdot (\sigma^2 + \epsilon)^{-1/2}x^k​=(xk​−μ)⋅(σ2+ϵ)−1/2 中包含 σ2\sigma^2σ2：

∂x^k∂σ2=(xk−μ)⋅(−12(σ2+ϵ)−3/2)=−12x^kσinv2\frac{\partial \hat{x}_k}{\partial \sigma^2} = (x_k - \mu) \cdot \left( -\frac{1}{2} (\sigma^2 + \epsilon)^{-3/2} \right) = -\frac{1}{2} \hat{x}_k \sigma_{\text{inv}}^2 ∂σ2∂x^k​​=(xk​−μ)⋅(−21​(σ2+ϵ)−3/2)=−21​x^k​σinv2​

结合全微分累加（对所有列 kkk 求和）：

∂L∂σ2=∑k=1Ndx^k∂x^k∂σ2=−12σinv2∑k=1N(dx^k⋅x^k)\frac{\partial L}{\partial \sigma^2} = \sum_{k=1}^N d\hat{x}_k \frac{\partial \hat{x}_k}{\partial \sigma^2} = -\frac{1}{2} \sigma_{\text{inv}}^2 \sum_{k=1}^N (d\hat{x}_k \cdot \hat{x}_k) ∂σ2∂L​=k=1∑N​dx^k​∂σ2∂x^k​​=−21​σinv2​k=1∑N​(dx^k​⋅x^k​)

为了让公式更简洁，我们定义一个中间标量累加量 c2c_2c2​：

c2=∑k=1Ndx^k⋅x^kc_2 = \sum_{k=1}^N d\hat{x}_k \cdot \hat{x}_k c2​=k=1∑N​dx^k​⋅x^k​

则：

∂L∂σ2=−12σinv2⋅c2\mathbf{\frac{\partial L}{\partial \sigma^2} = -\frac{1}{2} \sigma_{\text{inv}}^2 \cdot c_2} ∂σ2∂L​=−21​σinv2​⋅c2​

2. 关于均值 μ\muμ 的梯度：

μ\muμ 既通过 x^k\hat{x}_kx^k​ 分子中的 (xk−μ)(x_k - \mu)(xk​−μ) 影响输出，也通过 σ2\sigma^2σ2 的公式间接影响输出：

∂L∂μ=∑k=1Ndx^k∂x^k∂μ+∂L∂σ2∂σ2∂μ\frac{\partial L}{\partial \mu} = \sum_{k=1}^N d\hat{x}_k \frac{\partial \hat{x}_k}{\partial \mu} + \frac{\partial L}{\partial \sigma^2} \frac{\partial \sigma^2}{\partial \mu} ∂μ∂L​=k=1∑N​dx^k​∂μ∂x^k​​+∂σ2∂L​∂μ∂σ2​

其中：

∂x^k∂μ=−σinv\frac{\partial \hat{x}_k}{\partial \mu} = -\sigma_{\text{inv}} ∂μ∂x^k​​=−σinv​

∂σ2∂μ=∂∂μ[1N∑(xk−μ)2]=−2N∑(xk−μ)=0\frac{\partial \sigma^2}{\partial \mu} = \frac{\partial}{\partial \mu} \left[ \frac{1}{N} \sum (x_k - \mu)^2 \right] = -\frac{2}{N} \sum (x_k - \mu) = 0 ∂μ∂σ2​=∂μ∂​[N1​∑(xk​−μ)2]=−N2​∑(xk​−μ)=0

因为对偏离均值的项求和恒等于 0，因此间接项消掉了，仅剩直接项：

∂L∂μ=∑k=1Ndx^k(−σinv)=−σinv∑k=1Ndx^k\frac{\partial L}{\partial \mu} = \sum_{k=1}^N d\hat{x}_k (-\sigma_{\text{inv}}) = -\sigma_{\text{inv}} \sum_{k=1}^N d\hat{x}_k ∂μ∂L​=k=1∑N​dx^k​(−σinv​)=−σinv​k=1∑N​dx^k​

定义另一个中间标量累加量 c1c_1c1​：

c1=∑k=1Ndx^kc_1 = \sum_{k=1}^N d\hat{x}_k c1​=k=1∑N​dx^k​

则：

∂L∂μ=−σinv⋅c1\mathbf{\frac{\partial L}{\partial \mu} = -\sigma_{\text{inv}} \cdot c_1} ∂μ∂L​=−σinv​⋅c1​

第三步：对输入 xix_ixi​ 求偏导（终极公式）

应用全微分公式，把 xix_ixi​ 的三条路径全部合体：

∂L∂xi=dx^i∂x^i∂xi+∂L∂μ∂μ∂xi+∂L∂σ2∂σ2∂xi\frac{\partial L}{\partial x_i} = d\hat{x}_i \frac{\partial \hat{x}_i}{\partial x_i} + \frac{\partial L}{\partial \mu} \frac{\partial \mu}{\partial x_i} + \frac{\partial L}{\partial \sigma^2} \frac{\partial \sigma^2}{\partial x_i} ∂xi​∂L​=dx^i​∂xi​∂x^i​​+∂μ∂L​∂xi​∂μ​+∂σ2∂L​∂xi​∂σ2​

带入各个局部偏导数：

∂x^i∂xi=σinv\frac{\partial \hat{x}_i}{\partial x_i} = \sigma_{\text{inv}} ∂xi​∂x^i​​=σinv​

∂μ∂xi=1N\frac{\partial \mu}{\partial x_i} = \frac{1}{N} ∂xi​∂μ​=N1​

∂σ2∂xi=2N(xi−μ)=2Nx^iσinv−1\frac{\partial \sigma^2}{\partial x_i} = \frac{2}{N} (x_i - \mu) = \frac{2}{N} \hat{x}_i \sigma_{\text{inv}}^{-1} ∂xi​∂σ2​=N2​(xi​−μ)=N2​x^i​σinv−1​

代入后整理：

∂L∂xi=dx^i⋅σinv+(−σinv⋅c1)⋅1N+(−12σinv2⋅c2)⋅(2Nx^iσinv−1)\frac{\partial L}{\partial x_i} = d\hat{x}_i \cdot \sigma_{\text{inv}} + \left( -\sigma_{\text{inv}} \cdot c_1 \right) \cdot \frac{1}{N} + \left( -\frac{1}{2} \sigma_{\text{inv}}^2 \cdot c_2 \right) \cdot \left( \frac{2}{N} \hat{x}_i \sigma_{\text{inv}}^{-1} \right) ∂xi​∂L​=dx^i​⋅σinv​+(−σinv​⋅c1​)⋅N1​+(−21​σinv2​⋅c2​)⋅(N2​x^i​σinv−1​)

提取公因式 σinvN\frac{\sigma_{\text{inv}}}{N}Nσinv​​：

dxi=∂L∂xi=σinvN[N⋅dx^i−c1−x^i⋅c2]\mathbf{dx_i = \frac{\partial L}{\partial x_i} = \frac{\sigma_{\text{inv}}}{N} \left[ N \cdot d\hat{x}_i - c_1 - \hat{x}_i \cdot c_2 \right]} dxi​=∂xi​∂L​=Nσinv​​[N⋅dx^i​−c1​−x^i​⋅c2​]

其中：

  • dx^i=dyi⋅γid\hat{x}_i = dy_i \cdot \gamma_idx^i​=dyi​⋅γi​
  • c1=∑k=1Ndx^kc_1 = \sum_{k=1}^N d\hat{x}_kc1​=∑k=1N​dx^k​
  • c2=∑k=1N(dx^k⋅x^k)c_2 = \sum_{k=1}^N (d\hat{x}_k \cdot \hat{x}_k)c2​=∑k=1N​(dx^k​⋅x^k​)

官方示例代码对应的数学推导

一、符号定义

假设当前行的元素个数为 N

  • x：输入元素 xix_ixi​
  • mean：均值 μ=1N∑i=1Nxi\mu = \frac{1}{N} \sum_{i=1}^N x_iμ=N1​∑i=1N​xi​
  • rstd：标准差倒数 σinv=1σ2+ϵ\sigma_{\text{inv}} = \frac{1}{\sqrt{\sigma^2 + \epsilon}}σinv​=σ2+ϵ​1​
  • xhat：归一化后的特征 x^i=(xi−mean)⋅rstd\hat{x}_i = (x_i - \text{mean}) \cdot \text{rstd}x^i​=(xi​−mean)⋅rstd
  • dy：上游梯度 dyidy_idyi​
  • w：权重/缩放参数 wiw_iwi​（即 γi\gamma_iγi​）
  • wdy：梯度主项，定义为：$$\text{wdy}_i = w_i \cdot dy_i$$

我们的目标是求损失函数 LLL 对输入 xix_ixi​ 的偏导数 dx（即 ∂L∂xi\frac{\partial L}{\partial x_i}∂xi​∂L​）

二、数学推导步骤

根据链式法则，每个 xix_ixi​ 的变化会通过三条路径影响损失函数：

  1. 直接通过 xhat（分子上的 xix_ixi​）
  2. 间接通过 mean（均值 μ\muμ）
  3. 间接通过 rstd（方差 σ2\sigma^2σ2）

全微分推导展开如下：

dxi=∂L∂xi=∑k=1N∂L∂x^k⋅∂x^k∂xi\text{dx}_i = \frac{\partial L}{\partial x_i} = \sum_{k=1}^N \frac{\partial L}{\partial \hat{x}_k} \cdot \frac{\partial \hat{x}_k}{\partial x_i} dxi​=∂xi​∂L​=k=1∑N​∂x^k​∂L​⋅∂xi​∂x^k​​

由于

yk=wkx^k+bky_k = w_k \hat{x}_k + b_k yk​=wk​x^k​+bk​

所以

∂L∂x^k=dyk⋅wk=wdyk\frac{\partial L}{\partial \hat{x}_k} = dy_k \cdot w_k = \mathbf{\text{wdy}_k} ∂x^k​∂L​=dyk​⋅wk​=wdyk​

因此：

dxi=∑k=1Nwdyk⋅∂x^k∂xi\text{dx}_i = \sum_{k=1}^N \text{wdy}_k \cdot \frac{\partial \hat{x}_k}{\partial x_i} dxi​=k=1∑N​wdyk​⋅∂xi​∂x^k​​

拆解偏导数 ∂x^k∂xi\frac{\partial \hat{x}_k}{\partial x_i}∂xi​∂x^k​​

因为 x^k=(xk−mean)⋅rstd\hat{x}_k = (x_k - \text{mean}) \cdot \text{rstd}x^k​=(xk​−mean)⋅rstd，运用乘法求导法则：

∂x^k∂xi=∂(xk−mean)∂xi⋅rstd⏟项 A+(xk−mean)⋅∂rstd∂xi⏟项 B\frac{\partial \hat{x}_k}{\partial x_i} = \underbrace{\frac{\partial (x_k - \text{mean})}{\partial x_i} \cdot \text{rstd}}_{\text{项 A}} + \underbrace{(x_k - \text{mean}) \cdot \frac{\partial \text{rstd}}{\partial x_i}}_{\text{项 B}} ∂xi​∂x^k​​=项 A∂xi​∂(xk​−mean)​⋅rstd​​+项 B(xk​−mean)⋅∂xi​∂rstd​​​

我们分别求解 项 A 和 项 B：

求解项 A：

当 k=ik = ik=i 时

∂(xi−mean)∂xi=1−1N\frac{\partial (x_i - \text{mean})}{\partial x_i} = 1 - \frac{1}{N} ∂xi​∂(xi​−mean)​=1−N1​

当 k≠ik \neq ik=i 时

∂(xk−mean)∂xi=−1N\frac{\partial (x_k - \text{mean})}{\partial x_i} = -\frac{1}{N} ∂xi​∂(xk​−mean)​=−N1​

统一写成 δik\delta_{ik}δik​：

项 A=(δik−1N)⋅rstd\text{项 A} = \left( \delta_{ik} - \frac{1}{N} \right) \cdot \text{rstd} 项 A=(δik​−N1​)⋅rstd

求解项 B：

根据 rstd=(σ2+ϵ)−1/2\text{rstd} = (\sigma^2 + \epsilon)^{-1/2}rstd=(σ2+ϵ)−1/2，先求对 xix_ixi​ 的偏导：

∂rstd∂xi=−12(σ2+ϵ)−3/2⋅∂σ2∂xi=−12rstd3⋅(2N(xi−mean))=−1Nrstd2⋅xhati\frac{\partial \text{rstd}}{\partial x_i} = -\frac{1}{2} (\sigma^2 + \epsilon)^{-3/2} \cdot \frac{\partial \sigma^2}{\partial x_i} = -\frac{1}{2} \text{rstd}^3 \cdot \left( \frac{2}{N} (x_i - \text{mean}) \right) = -\frac{1}{N} \text{rstd}^2 \cdot \text{xhat}_i ∂xi​∂rstd​=−21​(σ2+ϵ)−3/2⋅∂xi​∂σ2​=−21​rstd3⋅(N2​(xi​−mean))=−N1​rstd2⋅xhati​

代入项 B 中：

项 B=(xk−mean)⋅(−1Nrstd2⋅xhati)=−1Nrstd⋅xhatk⋅xhati\text{项 B} = (x_k - \text{mean}) \cdot \left( -\frac{1}{N} \text{rstd}^2 \cdot \text{xhat}_i \right) = -\frac{1}{N} \text{rstd} \cdot \text{xhat}_k \cdot \text{xhat}_i 项 B=(xk​−mean)⋅(−N1​rstd2⋅xhati​)=−N1​rstd⋅xhatk​⋅xhati​

合并求和计算 dx

将 项 A 和 项 B 代回

dxi=∑k=1Nwdyk⋅∂x^k∂xi\text{dx}_i = \sum_{k=1}^N \text{wdy}_k \cdot \frac{\partial \hat{x}_k}{\partial x_i} dxi​=k=1∑N​wdyk​⋅∂xi​∂x^k​​

得：

dxi=∑k=1Nwdyk⋅[(δik−1N)⋅rstd−1Nrstd⋅xhatk⋅xhati]\text{dx}_i = \sum_{k=1}^N \text{wdy}_k \cdot \left[ \left( \delta_{ik} - \frac{1}{N} \right) \cdot \text{rstd} - \frac{1}{N} \text{rstd} \cdot \text{xhat}_k \cdot \text{xhat}_i \right] dxi​=k=1∑N​wdyk​⋅[(δik​−N1​)⋅rstd−N1​rstd⋅xhatk​⋅xhati​]

提取公因数 rstd 放到求和符号外面：

dxi=rstd⋅∑k=1Nwdyk[δik−1N−1Nxhatk⋅xhati]\text{dx}_i = \text{rstd} \cdot \sum_{k=1}^N \text{wdy}_k \left[ \delta_{ik} - \frac{1}{N} - \frac{1}{N} \text{xhat}_k \cdot \text{xhat}_i \right] dxi​=rstd⋅k=1∑N​wdyk​[δik​−N1​−N1​xhatk​⋅xhati​]

把求和符号按三项展开：

dxi=rstd⋅[∑k=1Nwdykδik⏟k=i 时保留，等于 wdyi−∑k=1NwdykN−∑k=1Nwdyk⋅xhatk⋅xhatiN]\text{dx}_i = \text{rstd} \cdot \left[ \underbrace{\sum_{k=1}^N \text{wdy}_k \delta_{ik}}_{k=i \text{ 时保留，等于 } \text{wdy}_i} - \sum_{k=1}^N \frac{\text{wdy}_k}{N} - \sum_{k=1}^N \frac{\text{wdy}_k \cdot \text{xhat}_k \cdot \text{xhat}_i}{N} \right] dxi​=rstd⋅​k=i 时保留，等于 wdyi​k=1∑N​wdyk​δik​​​−k=1∑N​Nwdyk​​−k=1∑N​Nwdyk​⋅xhatk​⋅xhati​​​

简化第一项，并将第二、三项中与 kkk 无关的 xhati\text{xhat}_ixhati​ 提出求和符号外：

dxi=rstd⋅[wdyi−∑k=1NwdykN−xhati⋅∑k=1N(xhatk⋅wdyk)N]\text{dx}_i = \text{rstd} \cdot \left[ \text{wdy}_i - \frac{\sum_{k=1}^N \text{wdy}_k}{N} - \text{xhat}_i \cdot \frac{\sum_{k=1}^N (\text{xhat}_k \cdot \text{wdy}_k)}{N} \right] dxi​=rstd⋅[wdyi​−N∑k=1N​wdyk​​−xhati​⋅N∑k=1N​(xhatk​⋅wdyk​)​]

三、提取 c1，c2

为了在 GPU 中高效做 Block 内归约（tl.sum），我们把上面公式里的两个归约求和部分抽出来：

c1=∑k=1N(xhatk⋅wdyk)N⟺c1 = tl.sum(xhat * wdy, axis=0) / Nc1 = \frac{\sum_{k=1}^N (\text{xhat}_k \cdot \text{wdy}_k)}{N} \quad \Longleftrightarrow \quad \texttt{c1 = tl.sum(xhat * wdy, axis=0) / N} c1=N∑k=1N​(xhatk​⋅wdyk​)​⟺c1 = tl.sum(xhat * wdy, axis=0) / N

c2=∑k=1NwdykN⟺c2 = tl.sum(wdy, axis=0) / Nc2 = \frac{\sum_{k=1}^N \text{wdy}_k}{N} \quad \Longleftrightarrow \quad \texttt{c2 = tl.sum(wdy, axis=0) / N} c2=N∑k=1N​wdyk​​⟺c2 = tl.sum(wdy, axis=0) / N

四、最终公式与代码对照

将定义好的 c1c1c1 和 c2c2c2 代回 dxi\text{dx}_idxi​：

dxi=rstd⋅(wdyi−(xhati⋅c1+c2))\mathbf{\text{dx}_i = \text{rstd} \cdot \left( \text{wdy}_i - \left( \text{xhat}_i \cdot c1 + c2 \right) \right)} dxi​=rstd⋅(wdyi​−(xhati​⋅c1+c2))

对应的 Triton 代码：

**局部部分和：**在第一个 Kernel 中，计算完 dx 之后，顺便在 SRAM 寄存器里算出了当前这一行对 γ\gammaγ 和 β\betaβ 的梯度贡献：

然后，为了避免几千个线程同时用原子操作（atomic_add）抢着向同一个全局变量写数据导致冲突卡死，代码里用了一个锁（Lock）与分组累加（GROUP_SIZE_M）的机制，把部分和存到了临时缓冲区 DW 和 DB 中。

**全局归约：**因为 γ\gammaγ 和 β\betaβ 是跨所有行共享的，最终的 dγd\gammadγ 和 dβd\betadβ 必须把所有行（n_rows）的梯度全部加起来

这里的 FINAL_DW 和 FINAL_DB 就是最终传给 PyTorch 反向传播用的 dw (dγd\gammadγ) 和 db (dβd\betadβ)

对应数学公式：

dw (Weight Gradient / dγd\gammadγ)：

dγj=∑row=1M(dyrow,j⋅x^row,j)⟺FINAL_DW = sum(dy * xhat, axis=rows)d\gamma_j = \sum_{\text{row}=1}^M \left( dy_{\text{row}, j} \cdot \hat{x}_{\text{row}, j} \right) \quad \Longleftrightarrow \quad \texttt{FINAL\_DW = sum(dy * xhat, axis=rows)} dγj​=row=1∑M​(dyrow,j​⋅x^row,j​)⟺FINAL_DW = sum(dy * xhat, axis=rows)

db (Bias Gradient / dβd\betadβ)：

dβj=∑row=1Mdyrow,j⟺FINAL_DB = sum(dy, axis=rows)d\beta_j = \sum_{\text{row}=1}^M dy_{\text{row}, j} \quad \Longleftrightarrow \quad \texttt{FINAL\_DB = sum(dy, axis=rows)} dβj​=row=1∑M​dyrow,j​⟺FINAL_DB = sum(dy, axis=rows)

Triton 官方教程的工程技巧与算法设计

在 PyTorch 或传统 CUDA 中，反向传播往往需要写两个 Kernel（一个在列方向上做 Reduce 算 c1,c2c_1, c_2c1​,c2​，另一个算出 dxdxdx）

但 Triton 官方教程通过 两阶段设计（Two-pass）和并行优化，将性能榨干到了极限：

  • _layer_norm_bwd_dx_fused：专门用来计算 输入梯度 dxdxdx。
    • 并行模式：按 Row（行） 进行 Block 划分（1 个 Program 处理 1 行或多行）
    • 优点：计算 c1c_1c1​ 和 c2c_2c2​ 需要对单行内的 NNN 个元素求和（Row Reduction）。由于同一个 Program 里的线程可以非常方便地用 tl.sum 做行内归约，因此计算 dxdxdx 可以做到极高的 SRAM 缓存复用！
  • _layer_norm_bwd_dwdb：专门用来计算 参数梯度 dγd\gammadγ 和 dβd\betadβ。
    • 并行模式：按 Column（列） 进行 Block 划分
    • 优点：dγid\gamma_idγi​ 是沿垂直方向（n_rows）把所有行的第 iii 列梯度加起来。按列切片能形成完美的 Coalesced Memory Access（合并访存），写入 DRAM 效率最高

总结

数学核心：把 μ\muμ 和 σ2\sigma^2σ2 的梯度通过链式法则化简，抽取出 c1c_1c1​ 和 c2c_2c2​ 两个标量

GPU 计算核心：计算 dxdxdx 时，每行只需要在 SRAM 里求出这两个标量 c1c_1c1​ 和 c2c_2c2​，就可以用点对点（Element-wise）的方式并发算出该行所有元素的 dxidx_idxi​，完全不需要跨线程同步

架构解耦：将 dxdxdx（按行并行）和 dγ,dβd\gamma, d\betadγ,dβ（按列并行）拆成两个 Kernel，完美适应 GPU 内存连续合并访问的物理特性
