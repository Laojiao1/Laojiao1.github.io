从零认识 GPU

从零认识 GPU

从显卡板到 GPU

显卡板上所有的元器件都是为 GPU 服务的：

GPU： 相当于显卡的大脑，负责几乎所有的计算任务。

视频接口： 可以让显卡直接把运算好的图像发送给显示器显示

PCIe 接口： 让显卡能够通过主板和 CPU 内存等其他元器件交互数据

供电模块： 保证了显卡有充足的电力分配，它们分布在 GPU 和显存的外围，由 PWM 芯片，电容，电感和 MOS 管组成（一个 MOS管 和一个电感就是一个供电项）

电源会从右上方的供电接口输入 +12V 的供电，之后由供电模块降压至 1.1V 与 1.35V，分别输送给GPU 和 显存

CPU 在计算时需要把数据临时存放在内存中，而高速运行的 GPU 同样需要把数据暂存到显存中：

GPU 周围的黑色小方块就是显存

假如这里的显存颗粒为 GDDR6X 1400MHz：单颗容量 2GB，32bit 位宽，每个周期内可以传输16 倍数据

显存的总带宽由频率、位宽、显存类型共同决定：

  • 频率代表一秒可以传输多少个周期
  • 位宽代表一次可以传输的数据量

总带宽 = 位宽 × 频率 × 倍增系数 = 256bit × 1400MHz × 16 = 716.8 GB/s，代表显存每秒能传输的数据量

一般来说，游戏的分辨率越高，贴图和模型越精致，对显存容量和带宽的要求就越高，但在显存够用的情况下，显卡的性能还是由显卡的核心 GPU 决定

**注意：**GPU 并不等于显卡，它指的是最中间的这块芯片。显卡指的是包括芯片，显存，供电，接口，电路板，以及散热模块的整体

GPU 结构

简化总览图：

主要由以下部分组成：

SM 流式多处理器

占据了 GPU 大部分面积，它负责了几乎所有的图形运算

（假设在该架构下）每个 SM 内有：

  • 4 processing block/SM
  • 1 Warp scheduler/processing block
  • 64 INT32, 64 FP32, 32 FP64 CUDA cores/SM
  • 4 Tensor cores/SM
  • SM 内共享 L1 缓存

Tensor Core：专为深度学习优化，矩阵运算，混合精度计算

思考：如果在矩阵计算的过程中，可以实现中间结果不写回，而是直接通过硬件电路向下传递，在一个时钟周期内就把整个矩阵运算的结果全部实现，是不是速度更快？

  • 如果把这个思想应用到 GPU ——> Tensor Core

  • 如果应用到一个全新的芯片上 ——> NPU

混合精度训练，底层就是通过 Tensor Core 来支持的，一个 Tensor Core 可以在一个时钟周期内，完成一个矩阵乘法和矩阵加法

两个 FP16 的操作数传入，进行全精度乘法，并且通过 FP32 进行累加（为了防止大数吃小数，丢失精度）

LD/ST：Load/Store Units 负责从数据的加载和存储

SFU（special Function Units）：负责处理特殊数学函数和复杂的计算操作，例如三角函数，指针函数，对数函数，以及平方根等

假设这颗核心里一共有 76 组 SM 单元，每个 SM 单元里包含 128 个流处理器，那么总共 9728 个流处理器，英伟达把这些流处理器叫做 CUDA 核心，显卡的流处理器数量越多，频率越高，性能越强

如果把每组SM类比成一个CPU核心，那么这颗GPU就相当于一颗 76 核，9728 线程的处理器

CPU 就像经验丰富的数学家，能够处理更加复杂的任务；而 GPU 核心更像是只会四则运算的小学生，适合做简单的并行计算，在游戏图像处理和AI计算里，都需要这样大量简单计算的场景，因此显卡核心的数量优势，就比 CPU 核心的质量优势更加有效率

假设这颗核心可以让 9728 个CUDA核心同时进行单精度浮点运算，在2800MHz情况下，可以提供大约 2800MHz × 9728 × 2 = 52 TFLOPS 的单精度浮点算力，意味着每秒钟能计算 54 万亿次

在这颗 GPU 核心中，所有的 CUDA 都能计算单精度浮点数，除了能计算单精度浮点数 FP32 之外，同时向下兼容精度更低的半精度浮点数 FP16，但只有一半的 CUDA 能支持 INT32 的整数计算

需要说明的是 GPU 的算力和架构有关，架构是 GPU 的设计方案，设计方案越先进，相同算力下的图形渲染的效率越高，所以 NVIDIA 在官网标注算力的同时也会标注 GPU 架构。单精度浮点算力核架构共同决定了 GPU 的性能

除了游戏之外，GPU 还承担了许多 AI 相关的任务。在 CUDA 核心的右边是 Tensor Core 张量核心

它非常适合做 AI 相关的深度学习计算，在这颗核心中，所有的 Tensor Core 一共可以提供 780 AI TOPS 的算力

比如游戏里的 DLSS（俗称大力水手） 模式，可以调用 Tensor Core，用更低的分辨率渲染，再通过 AI 上采样到更高的分辨率，从而提升游戏的流畅度

L2 缓存

最好让计算从L1缓存读取数据，进行尽可能多的计算，这样才能充分利用 GPU 算力，这也是 Flash Attention 优化大模型的出发点

NVENC 视频编码器、NVDEC 视频解码器

视频解码器让显卡能把 0101 的二进制数据转换成连续播放的视频画面，解码器性能过弱，就可能在播放视频时发生卡顿掉帧

视频编码器可以让你把拍摄到的视频数据以新的编码方式压缩成期望的格式和大小，编码器性能过弱则会在剪辑视频，导出时浪费过多时间

显存控制器、PCIe 控制器

显存控制器让 GPU 和显存得以顺利交互数据

PCIe 控制器让显卡能和主板上的 CPU，内存，硬盘等其他元器件交互数据
